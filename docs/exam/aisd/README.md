# Шпаргалка «АиСД fast» — PDF к устному экзамену

Один PDF со **всеми 15 билетами** экзамена «Алгоритмы и структуры данных»
(2025–2026), разложенными по единому формату:

> **Постановка → Идея → Алгоритм → Теорема·корректность → Идея доказательства →
> Строгое доказательство → Сложность $T_{wc}(n)$ → Ограничения → Пример (трассировка
> + SVG) → На экзамене.**

Разделы: Графовые алгоритмы (4) · Строковые алгоритмы (5) · Парадигмы разработки (6).
Заканчивается диаграммой классов сложности P / NP / NP-полные.

## Сборка

```bash
brew install typst      # один раз
./build.sh              # → aisd-fast.pdf
```

`build.sh` зовёт `typst compile main.typ aisd-fast.pdf --root <repo>`.
`--root` нужен, чтобы Typst видел SVG-фигуры в `public/figures/aisd/`.

## Структура

| Файл | Что |
|---|---|
| `main.typ` | обложка, оглавление, `#include` разделов |
| `template.typ` | стиль + хелперы: `ticket()`, рубрики (`task/idea/algo/thm/sketch/proof/cx/lim/ex/tip`), `figcard()`/`figrow()` (тёмные SVG-карточки на светлой странице) |
| `parts/01-graph.typ` | билеты 1–4 (графы) |
| `parts/02-str.typ` | билеты 1–5 (строки) |
| `parts/03-para.typ` | билеты 1–5 (парадигмы) |
| `parts/99-pnp.typ` | билет 6 (сведение, P/NP, NP-полнота) |

## Фигуры

SVG берутся из `public/figures/aisd/*.svg` — те же, что показывает квиз в приложении
(`src/components/Figure.jsx`). Тёмный фон фигур обёрнут в карточку-панель. Чтобы
перегенерировать фигуры — см. `scripts/figures/` (Python + matplotlib, `build.py`).
