# Квиз «Алгоритмы и структуры данных» (`aisd`) — дизайн

**Дата:** 2026-06-21
**Ветка:** feature/matstat-exam-prep (новый квиз добавляется поверх мульти-квиз платформы)

## Цель

Добавить третий квиз на платформу (рядом с `finance` и `matstat`) — подготовку к
устному экзамену по АиСД 2025-2026. Экзаменационный билет = 3 вопроса, по одному из
разделов: Графовые алгоритмы / Строковые алгоритмы / Парадигмы разработки. Ответ на
вопросы разделов 1-2 сопровождается: (1) обоснованием асимптотики $T_{avg}(n)$,
(2) комментарием об ограничениях применимости, (3) пошаговой иллюстрацией на примере.

Квиз тренирует этот материал через банк MCQ-вопросов с LaTeX, флеш-карты, шпаргалку
сложностей и пошаговые SVG-иллюстрации.

## Ключевые решения (из брейншторминга)

1. **Темы-чипы = 3 раздела** (`graph` / `str` / `para`). Исходники бьём по 15 подпунктам.
2. **Сбалансированный микс вопросов:** асимптотика + трассировка + ограничения +
   понятийные + числовые.
3. **Пошаговые иллюстрации — статичные SVG** через Python/matplotlib (как matstat),
   многопанельные «шаг 1 → шаг 2 → шаг 3».
4. **Полный объём** (паритет с matstat): ~90-120 вопросов, ~60-80 флеш-карт,
   ~50-70 формул/фактов сложности, ~28-32 фигуры.

## Архитектура и размещение

Повторяем модульный паттерн matstat — самодостаточный модуль квиза.

```
api/_data/aisd/

  questions.js           # TOPICS (3) + конкатенация банка из подмодулей
  glossary.js            # ~50-60 терминов
  flashcards.js          # агрегатор
  formulas.js            # агрегатор шпаргалки сложностей
  achievements.js        # ачивки (клон паттерна, topicMastery -> graph)
```

`flashcards`, `formulas`. Агрегаторы конкатенируют. Файлы маленькие (~6-8 вопросов),
подпункты авторятся/проверяются независимо.

## Карта покрытия тем

### РАЗДЕЛ 1 — Графовые алгоритмы (`graph`, ~30 вопросов)

- **Флойд–Уоршелл** (`floyd.js`): матрицы $D^{(k)}$, восстановление пути, $O(n^3)$,
  отриц. рёбра без отриц. циклов; трассировка $d[i][j]=\min(d[i][j],d[i][k]+d[k][j])$.
- **Макс. поток** (`flow.js`): Форд-Фалкерсон / Эдмондс-Карп / Диниц, остаточная сеть,
  увеличивающий путь, max-flow=min-cut; сложности $O(Ef)$/$O(VE^2)$/$O(V^2E)$.
- **Паросочетания** (`matching.js`): макс/наибольшее/полное, чередующийся/увеличивающий
  путь, Кун $O(VE)$, Хопкрофт-Карп $O(E\sqrt V)$, двудольность.
- **Раскраска** (`coloring.js`): жадный алгоритм, $\chi(G)$, хроматический многочлен,
  оценка $\Delta+1$, зависимость от порядка вершин.

### РАЗДЕЛ 2 — Строковые алгоритмы (`str`, ~38 вопросов)

- **Точный поиск** (`exact.js`): KMP (префикс-функция $\pi$, $O(n+m)$),
  Бойер-Мур-Хорспул (таблица сдвигов, средн. сублинейно, худш. $O(nm)$).
- **Приближённый поиск** (`edit.js`): Левенштейн ДП $O(nm)$, Дамерау-Левенштейн
  (+транспозиции); трассировка ячеек ДП.
- **Ахо-Корасик** (`aho.js`): бор, fail/словарные ссылки, $O(n+m+z)$.
- **Сортировки строк** (`strsort.js`): string mergesort, тернарный string quicksort,
  MSD radix, роль LCP, применимость.
- **Кодирование** (`coding.js`): RLE, Хаффман (дерево, префиксный код, жадность),
  LZW (словарь).

### РАЗДЕЛ 3 — Парадигмы разработки (`para`, ~33 вопроса)

- **Жадные** (`greedy.js`): доказательство оптимальности (обмен/матроид), примеры.
- **ДП** (`dp.js`): опт. подструктура, перекрытие подзадач, vs «разделяй-и-властвуй»,
  рюкзак 0/1 $O(nW)$, псевдополиномиальность.
- **Ветви и границы** (`branch.js`): дерево решений, верх./ниж. границы, отсечение,
  рюкзак / коммивояжёр / назначения.
- **Приближённые** (`approx.js`): коэффициент аппроксимации, отклонение, PTAS/FPTAS
  для рюкзака.
- **Стохастические** (`random.js`): Лас-Вегас vs Монте-Карло, Каргер (min-cut),
  вероятностный анализ.
- **Сведения, P/NP** (`complexity.js`): линейное/полиномиальное сведение, P, NP,
  NP-полнота, неразрешимость, примеры.

## Форматы контента (идентичны matstat — без изменений в движке)

- **Вопрос:** `{ id, topic, difficulty(1-3), q, options[], correct[], multi, explain, figure?, figureCaption? }`
- **Флеш-карта:** `{ id, topic, front, back, figure? }`
- **Формула:** `{ id, topic, title, latex, note?, figure? }`
- **Термин:** `{ t, topic, d }`

LaTeX в `q/options/explain/front/back`; формулы — display-LaTeX.

## Пайплайн фигур (~28-32 SVG)

Новые `scripts/figures/fig_graph.py`, `fig_str.py`, `fig_para.py` →
`public/figures/aisd/*.svg`, через тот же `build.py`. Графы — `networkx`+`matplotlib`
(добавить `networkx` в `requirements.txt`).

**Гарантия корректности:** где фигура иллюстрирует расчёт (ДП-таблица Левенштейна,
дерево Хаффмана, префикс-функция), Python-скрипт вычисляет значения сам, а вопрос
ссылается на те же числа — единый источник правды.

## Точность контента

После авторинга каждой темы — проход верификации агентом (проверка ключей ответов,
трассировок, сложностей). Все созданные SVG визуально перепроверяются.
